# Gophermart Loyalty System

Gophermart — это система накопительного лояльности для интернет-магазина, позволяющая пользователям регистрировать заказы, получать баллы лояльности за покупки и использовать их для оплаты будущих заказов.

## Краткое описание

Система реализует HTTP API для управления накопительным счетом пользователей, включая регистрацию, аутентификацию, загрузку номеров заказов, начисление и списание баллов лояльности. Архитектурно проект построен на основе микросервисного подхода с отдельным сервисом начислений (accrual), с которым взаимодействует через HTTP API.

## Использованные подходы и решения

- **Микросервисная архитектура**: Основной сервис и сервис начислений разделены, что позволяет масштабировать систему и обеспечивает гибкость.
- **JWT-аутентификация**: Для аутентификации пользователей используется JWT-токены, хранящиеся в HTTP-куках.
- **Worker-паттерн**: Обработка заказов осуществляется асинхронно с помощью воркеров, что позволяет эффективно обрабатывать большое количество заказов.
- **Алгоритм Луна**: Проверка валидности номеров заказов осуществляется с помощью алгоритма Луна.
- **HTTP-сжатие**: Поддержка сжатия данных в HTTP-запросах и ответах для уменьшения трафика.
- **Управление ошибками**: Использование собственной системы обработки ошибок с различными типами ошибок и кодами HTTP-ответов.
- **Ретраи и таймауты**: Использование retry-механизмов и таймаутов при работе с внешними сервисами.

## Установка и запуск

### Требования
- Go 1.24+
- PostgreSQL 12+
- make (опционально)

### Установка

1. Клонируйте репозиторий:
```bash
git clone https://github.com/username/gophermart.git
cd gophermart
```

2. Установите зависимости:
```bash
go mod download
```

3. Настройте переменные окружения или используйте флаги командной строки:
```bash
export DATABASE_URI="postgres://user:password@localhost:5432/gophermart?sslmode=disable"
export RUN_ADDRESS=":8080"
export ACCRUAL_SYSTEM_ADDRESS="http://localhost:8085"
```

4. Запустите приложение:
```bash
go run cmd/gophermart/main.go
```

### Конфигурация

Сервис поддерживает конфигурацию следующими методами:

- Адрес и порт запуска сервиса: переменная окружения `RUN_ADDRESS` или флаг `-a`
- Адрес подключения к базе данных: переменная окружения `DATABASE_URI` или флаг `-d`
- Адрес системы расчёта начислений: переменная окружения `ACCRUAL_SYSTEM_ADDRESS` или флаг `-r`
- Режим окружения: переменная окружения `ENVIRONMENT` или флаг `-e`

## Примеры использования

### Регистрация пользователя
```bash
curl -X POST http://localhost:8080/api/user/register \
  -H "Content-Type: application/json" \
  -d '{"login":"user123","password":"password123"}'
```

### Аутентификация пользователя
```bash
curl -X POST http://localhost:8080/api/user/login \
  -H "Content-Type: application/json" \
  -d '{"login":"user123","password":"password123"}'
```

### Загрузка номера заказа
```bash
curl -X POST http://localhost:8080/api/user/orders \
  -H "Content-Type: text/plain" \
  -H "Cookie: Authorization=JWT_TOKEN" \
  -d "12345678903"
```

### Получение списка заказов пользователя
```bash
curl -X GET http://localhost:8080/api/user/orders \
  -H "Cookie: Authorization=JWT_TOKEN"
```

### Получение баланса пользователя
```bash
curl -X GET http://localhost:8080/api/user/balance \
  -H "Cookie: Authorization=JWT_TOKEN"
```

### Списание баллов
```bash
curl -X POST http://localhost:8080/api/user/balance/withdraw \
  -H "Content-Type: application/json" \
  -H "Cookie: Authorization=JWT_TOKEN" \
  -d '{"order":"237725624","sum":751}'
```

## Архитектура / основные модули

### Структура проекта
```
├── cmd/
│   └── gophermart/          # Основной сервис
├── internal/
│   ├── auth/                # Аутентификация и JWT
│   ├── config/              # Конфигурация приложения
│   ├── domain/              # Доменные ошибки
│   ├── gophermart/          # Бизнес-логика
│   ├── job/                 # Интерфейсы для задач
│   ├── logger/              # Логирование
│   ├── luhn/                # Алгоритм Луна
│   ├── mocks/               # Моки для тестирования
│   ├── models/              # Модели данных
│   ├── server/              # HTTP-сервер
│   ├── storage/             # Хранилище данных (PostgreSQL)
│   ├── transport/           # HTTP-транспорт
│   └── worker/              # Обработчики задач
├── migrations/              # SQL-миграции
```

### Основные компоненты

- **Gophermart Service**: Основной сервис, реализующий бизнес-логику приложения
- **HTTP Server**: Веб-сервер на базе `go-chi`, обрабатывающий HTTP-запросы
- **PostgreSQL Storage**: Хранилище данных, реализующее интерфейс Repository
- **Worker System**: Асинхронная система обработки заказов с помощью воркеров
- **JWT Middleware**: Промежуточное ПО для аутентификации пользователей
- **Order Processor**: Компонент, отвечающий за обработку заказов и взаимодействие с системой начислений
- **Balance Processor**: Компонент, отвечающий за обновление балансов пользователей
